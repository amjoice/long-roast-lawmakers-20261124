A Python program that writes one satirical sentence roasting a lawmaker who regulates crypto exchanges but cannot convert a file to PDF. The senator renames his bill `FINAL_v2_ACTUALLY_FINAL.docx`, nobody in the building can turn it into a PDF, and his office responds the only way lawmakers know how: by forming a subcommittee to investigate the file.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
cat output/entry.txt
```

The program is stdlib-only, deterministic, and writes exactly one sentence (201 characters) to `<output dir>/entry.txt`.
